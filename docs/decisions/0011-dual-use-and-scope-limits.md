# 0011. Dual use and scope limits

## Context
An engine that finds which rule holds a bundle together finds it for whoever runs it. The same checks (cosmetic reform detection, revocable exits, persistence) serve an optimizer for control, the dark twin of liberation.

## Decision
This project does not encode named private individuals. It builds no optimization mode that searches for the cheapest way to keep a property violated or an exit revocable. It runs no simulated populations standing in for real marginalized groups without their participation (arXiv:2604.07838, CHI 2026 PoliSim workshop; see also 0008). The license is chosen with the dark twin in mind. GPL-3.0 is what IG-Parser uses; the choice stays open here.

## Alternatives rejected
Keeping the tool private: it defeats the documentation and participation goals. No limits: the tool is small enough to be reimplemented, so these limits are about what this project publishes and endorses, not a technical lock.

## Consequences
Some useful-looking features are declined on purpose, and the line between checking a property and optimizing against it needs judgment case by case. Reimplementation by others remains possible and is outside our control. The license decision is deferred and needs its own ADR, which should weigh copyleft against the dark twin before the first release.

## Status
Accepted 2026-11-03: public repo, permissive license with attribution (see docs/intent.md); the specific license choice is Apache-2.0 unless the author changes it.
